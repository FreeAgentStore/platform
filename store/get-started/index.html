Get Started

Use AI tools in your browser, or build your own and publish to the store.

Use an agent

1 Browse the store

Visit freeagentstore.online and pick an agent. Filter by Libraries, Models, or Agents.

2 Try it

Click "Open" to use the agent directly. Libraries and models work instantly — no sign-up needed.

3 Add to your app

Import via npm or direct ESM URL:

npm install @freeagentstore/sentiment

import { analyzeSentiment } from '@freeagentstore/sentiment'

Or import directly (zero install):

<script type="module">
  import { analyzeSentiment } from 'https://freeagentstore.online/pkg/sentiment/index.js'
</script>

Build your own agent

1 Scaffold

npx @freeagentstore/cli init my-agent --template heuristic

Templates: heuristic (pure TS), built-in-ai (Chrome AI), model (ONNX)

2 Develop

cd my-agent
npm install
npm run dev

Edit src/index.ts — your agent's core logic. Keep it pure TypeScript (no DOM deps) so it works as both a library and a webapp.

3 Publish

npx @freeagentstore/cli publish

Creates a GitHub repo, deploys to R2, registers the route. Your agent is live at freeagentstore.online/a/my-agent/.

For agents that need AI

If your agent calls OpenAI, Claude, or Gemini:

  1. Sign in with GitHub
  2. Go to API Keys and add your provider key
  3. Your agent calls the platform proxy — the key is injected server-side
  4. You pay your provider directly. The platform charges nothing.

MCP integration

Connect FreeAgentStore to Claude, Cursor, or any MCP-compatible tool:

npx mcp-remote https://mcp.freeagentstore.online/mcp
