Build a Model Agent

A model agent runs ML inference directly in the browser using WebGPU or WASM. The model downloads once, caches in the browser, and runs entirely on the user's device. Zero server cost, full privacy.

Model + heuristic = real value. The best model agents don't just return raw model output. They map model predictions to domain-specific knowledge -- turning ImageNet labels into breed info, or food classifications into calorie estimates.

Supported frameworks

Framework Package Best for
Transformers.js @huggingface/transformers HuggingFace models -- classification, NLP, vision, audio. Primary choice.
TensorFlow.js @tensorflow/tfjs TF-specific models -- MoveNet (pose), BlazeFace, speech commands.
ONNX Runtime Web onnxruntime-web Custom ONNX models, fine-tuned models, specialized architectures.

Transformers.js is the recommended default. It has the largest model library, automatic WebGPU/WASM fallback, and built-in caching. Use TensorFlow.js or ONNX Runtime only when your model requires them.

Model size guidelines

  • Under 50 MB -- ideal. Fast download, works on mobile. Examples: MiniLM (23 MB), MobileViT-small (24 MB).
  • 50-200 MB -- acceptable. Show download progress. Examples: Whisper-small (150 MB), ViT-base (85 MB).
  • 200-500 MB -- use with caution. Warn users about download size. Examples: Kokoro TTS (82 MB quantized).
  • Over 500 MB -- generally too large for browser use. Consider a smaller variant or quantized version.

Full example: Breed Identifier

This agent loads MobileViT-small (24 MB), classifies images, maps ImageNet labels to dog/cat breeds, and adds breed-specific information (size, temperament, exercise needs).

web/src/classifier.ts

import { pipeline, type ImageClassificationPipeline } from '@huggingface/transformers';

// ── Types ────────────────────────────────────────────────────────────────────

export interface BreedResult {
  breed: string;
  confidence: number;
  info: BreedInfo | null;
  rawLabel: string;
  isAnimal: boolean;
}

export interface BreedInfo {
  species: 'dog' | 'cat';
  size: 'small' | 'medium' | 'large';
  temperament: string[];
  exerciseNeeds: 'low' | 'moderate' | 'high';
  lifespan: string;
  weight: string;
}

// ── Model management ─────────────────────────────────────────────────────────

let classifier: ImageClassificationPipeline | null = null;

export async function initModel(
  onProgress?: (progress: number) => void
): Promise<void> {
  if (classifier) return;

  classifier = await pipeline(
    'image-classification',
    'Xenova/mobilevit-small',
    {
      progress_callback: (data: { progress?: number }) => {
        if (data.progress !== undefined && onProgress) {
          onProgress(Math.round(data.progress));
        }
      },
    },
  );
}

export async function identifyBreed(
  image: HTMLImageElement | HTMLCanvasElement
): Promise<BreedResult> {
  if (!classifier) throw new Error('Model not loaded. Call initModel() first.');

  const results = await classifier(image, { topk: 5 });
  const top = results[0];
  const rawLabel = top.label.toLowerCase();
  const confidence = Math.round(top.score * 100) / 100;

  // Try to match against breed database
  const breed = matchBreed(rawLabel);

  if (breed) {
    return {
      breed: breed.name,
      confidence,
      info: breed.info,
      rawLabel: top.label,
      isAnimal: true,
    };
  }

  return {
    breed: formatLabel(top.label),
    confidence,
    info: null,
    rawLabel: top.label,
    isAnimal: isAnimalLabel(rawLabel),
  };
}

// ── Label matching ───────────────────────────────────────────────────────────

function matchBreed(label: string): BreedEntry | null {
  // Direct match
  if (BREED_DB[label]) return BREED_DB[label];

  // Partial match -- check if label contains a known breed name
  for (const [key, entry] of Object.entries(BREED_DB)) {
    if (label.includes(key) || key.includes(label)) {
      return entry;
    }
  }

  return null;
}

function isAnimalLabel(label: string): boolean {
  const animalKeywords = [
    'dog', 'puppy', 'hound', 'terrier', 'spaniel', 'retriever', 'shepherd',
    'poodle', 'bulldog', 'collie', 'setter', 'pointer', 'mastiff',
    'cat', 'kitten', 'tabby', 'persian', 'siamese',
  ];
  return animalKeywords.some(k => label.includes(k));
}

function formatLabel(label: string): string {
  return label
    .split(/[_,]/)
    .map(w => w.trim())
    .filter(Boolean)
    .map(w => w.charAt(0).toUpperCase() + w.slice(1))
    .join(' ');
}

web/src/App.tsx

import { useState, useRef, useCallback } from 'react';
import { initModel, identifyBreed, type BreedResult } from './classifier';

type ModelState = 'idle' | 'downloading' | 'ready' | 'error';

export default function App() {
  const [modelState, setModelState] = useState<ModelState>('idle');
  const [progress, setProgress] = useState(0);
  const [result, setResult] = useState<BreedResult | null>(null);
  const [imageUrl, setImageUrl] = useState<string | null>(null);
  const [analyzing, setAnalyzing] = useState(false);
  const fileInputRef = useRef<HTMLInputElement>(null);

  const loadAndAnalyze = useCallback(async (imgEl: HTMLImageElement) => {
    if (modelState !== 'ready') {
      setModelState('downloading');
      try {
        await initModel((p) => setProgress(p));
        setModelState('ready');
      } catch {
        setModelState('error');
        return;
      }
    }
    setAnalyzing(true);
    try {
      const r = await identifyBreed(imgEl);
      setResult(r);
    } finally {
      setAnalyzing(false);
    }
  }, [modelState]);

  const processImage = useCallback((file: File) => {
    if (!file.type.startsWith('image/')) return;
    const url = URL.createObjectURL(file);
    setImageUrl(url);
    setResult(null);
    const img = new Image();
    img.crossOrigin = 'anonymous';
    img.onload = () => loadAndAnalyze(img);
    img.src = url;
  }, [loadAndAnalyze]);

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (file) processImage(file);
  };

  return (
    <div style={{ maxWidth: 480, margin: '2rem auto', padding: '0 1rem' }}>
      <h1>Breed Identifier</h1>
      <p>Upload a photo of a dog or cat to identify the breed.</p>

      <input
        ref={fileInputRef}
        type="file"
        accept="image/*"
        onChange={handleFileChange}
        style={{ marginBottom: '1rem' }}
      />

      {modelState === 'downloading' && (
        <div>
          <p>Downloading model... {progress}%</p>
          <div style={{ background: '#262626', borderRadius: 8, height: 8 }}>
            <div style={{ width: `${progress}%`, background: '#7c3aed', height: 8, borderRadius: 8, transition: 'width 0.3s' }} />
          </div>
        </div>
      )}

      {imageUrl && <img src={imageUrl} alt="Preview" style={{ maxWidth: '100%', borderRadius: 12, margin: '1rem 0' }} />}

      {analyzing && <p>Analyzing...</p>}

      {result && (
        <div style={{ background: '#171717', border: '1px solid #262626', borderRadius: 12, padding: '1rem' }}>
          <h2>{result.breed}</h2>
          <p>Confidence: {Math.round(result.confidence * 100)}%</p>
          {result.info && (
            <ul>
              <li>Species: {result.info.species}</li>
              <li>Size: {result.info.size}</li>
              <li>Temperament: {result.info.temperament.join(', ')}</li>
              <li>Exercise: {result.info.exerciseNeeds}</li>
              <li>Lifespan: {result.info.lifespan}</li>
              <li>Weight: {result.info.weight}</li>
            </ul>
          )}
          {!result.info && <p style={{ color: '#a3a3a3' }}>Raw classification: {result.rawLabel}</p>}
        </div>
      )}
    </div>
  );
}

3 Add model download progress

Always show download progress. Models range from 23 MB to 500 MB. Users need to know what's happening.

The progress_callback in Transformers.js fires during model download. Cache Storage holds the model after first download -- subsequent loads are instant.

Caching

Transformers.js uses the browser's Cache Storage API automatically. After the first download, the model loads from cache. Users can verify cached models in DevTools → Application → Cache Storage.

For ONNX Runtime or TensorFlow.js, implement caching manually:

async function loadModelWithCache(url: string): Promise<ArrayBuffer> {
  const cache = await caches.open('model-cache-v1');
  const cached = await cache.match(url);
  if (cached) return cached.arrayBuffer();

  const response = await fetch(url);
  cache.put(url, response.clone());
  return response.arrayBuffer();
}

WebGPU vs WASM

Transformers.js automatically selects the best backend:

  • WebGPU -- 5-20x faster than WASM. Available in Chrome 113+, Edge 113+, Firefox Nightly. Hardware-accelerated on GPU.
  • WASM -- universal fallback. Works in all browsers. Runs on CPU. Slower but reliable.

You can force a specific backend if needed:

import { env } from '@huggingface/transformers';

// Force WebGPU (will fail if unavailable)
env.backends.onnx.wasm.proxy = false;

// Force WASM (skip WebGPU detection)
env.backends.onnx.wasm.proxy = true;

In practice, let Transformers.js auto-detect. The fallback is seamless.

Using TensorFlow.js

For models only available in TensorFlow format (pose estimation, face detection, audio classification):

import * as tf from '@tensorflow/tfjs';
import '@tensorflow/tfjs-backend-webgl';
import * as poseDetection from '@tensorflow-models/pose-detection';

// Load MoveNet for pose estimation
const detector = await poseDetection.createDetector(
  poseDetection.SupportedModels.MoveNet,
  {
    modelType: poseDetection.movenet.modelType.SINGLEPOSE_THUNDER,
    enableSmoothing: true,
  }
);

// Detect poses from video frame
const poses = await detector.estimatePoses(videoElement);
for (const pose of poses) {
  for (const keypoint of pose.keypoints) {
    console.log(`${keypoint.name}: (${keypoint.x}, ${keypoint.y}) score=${keypoint.score}`);
  }
}

Using ONNX Runtime Web

For custom or fine-tuned ONNX models:

import * as ort from 'onnxruntime-web';

// Load model (with Cache Storage caching)
const modelBuffer = await loadModelWithCache('/models/my-model.onnx');
const session = await ort.InferenceSession.create(modelBuffer, {
  executionProviders: ['webgpu', 'wasm'],  // fallback chain
});

// Run inference
const inputTensor = new ort.Tensor('float32', inputData, [1, 3, 224, 224]);
const results = await session.run({ input: inputTensor });
const output = results['output'].data;
