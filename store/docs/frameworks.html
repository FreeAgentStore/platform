Supported AI Frameworks

Every framework that works in FAGS agents. All run in the browser. Some need the platform proxy (for API key injection), some run entirely on-device.

At a glance

Framework Package Use case Browser? Store
Transformers.js @huggingface/transformers HuggingFace models (classification, NLP, vision, audio) Yes FAGS
TensorFlow.js @tensorflow/tfjs TF models (pose, face, audio) Yes FAGS
ONNX Runtime onnxruntime-web Custom ONNX models Yes FAGS
LangChain.js langchain Chains, RAG, agents, memory Yes (with proxy) FAGS
Vercel AI SDK ai Streaming, tool calling, multi-provider Yes (with proxy) FAGS
Chrome Built-in AI Browser API Simple generation, summarization Yes (Chrome only) FAGS
Ollama localhost:11434 Local LLM (user installs) Yes (local server) FAGS
Workers AI CF binding Server-side models No PAGS
FAGS vs PAGS: FAGS (FreeAgentStore) runs everything in the browser -- zero server cost. PAGS (ProAgentStore) runs server-side on Cloudflare Workers AI with D1, R2, Durable Objects. If your agent needs server-side inference, it belongs on PAGS.

Transformers.js

The primary framework for FAGS model agents

Run HuggingFace models in the browser with WebGPU acceleration and WASM fallback. 1000+ models available. Automatic caching via Cache Storage.

npm install @huggingface/transformers

Image classification

import { pipeline } from '@huggingface/transformers';

const classifier = await pipeline('image-classification', 'Xenova/mobilevit-small');

// From an <img> element
const results = await classifier(imageElement, { topk: 3 });
// [{ label: 'golden retriever', score: 0.92 }, ...]

// From a URL
const results2 = await classifier('https://example.com/photo.jpg');

Text classification (sentiment)

import { pipeline } from '@huggingface/transformers';

const sentiment = await pipeline(
  'sentiment-analysis',
  'Xenova/distilbert-base-uncased-finetuned-sst-2-english'
);

const result = await sentiment('This product is amazing!');
// [{ label: 'POSITIVE', score: 0.9998 }]

Text embeddings (for semantic search)

import { pipeline } from '@huggingface/transformers';

const embedder = await pipeline('feature-extraction', 'Xenova/all-MiniLM-L6-v2');

const output = await embedder('How do I use WebGPU?', {
  pooling: 'mean',
  normalize: true,
});
const embedding = Array.from(output.data);
// 384-dimensional vector -- use for cosine similarity search

Speech to text

import { pipeline } from '@huggingface/transformers';

const transcriber = await pipeline('automatic-speech-recognition', 'Xenova/whisper-small');

// From an audio file (Blob, ArrayBuffer, or URL)
const result = await transcriber(audioBlob);
// { text: 'Hello, this is a test.' }

Object detection

import { pipeline } from '@huggingface/transformers';

const detector = await pipeline('object-detection', 'Xenova/detr-resnet-50');

const results = await detector(imageElement);
// [{ label: 'cat', score: 0.98, box: { xmin: 10, ymin: 20, xmax: 200, ymax: 300 } }, ...]

Zero-shot classification

import { pipeline } from '@huggingface/transformers';

const classifier = await pipeline(
  'zero-shot-classification',
  'Xenova/mobilebert-uncased-mnli'
);

const result = await classifier(
  'I need to book a flight to New York next week.',
  ['travel', 'finance', 'food', 'technology']
);
// { labels: ['travel', ...], scores: [0.95, ...] }

TensorFlow.js

For TF-specific models and task libraries

Use when a model is only available in TensorFlow format, or when using TF task-specific libraries (pose detection, face mesh, hand tracking, audio classification).

npm install @tensorflow/tfjs

Pose estimation (MoveNet)

import * as tf from '@tensorflow/tfjs';
import '@tensorflow/tfjs-backend-webgl';
import * as poseDetection from '@tensorflow-models/pose-detection';

await tf.ready();

const detector = await poseDetection.createDetector(
  poseDetection.SupportedModels.MoveNet,
  { modelType: poseDetection.movenet.modelType.SINGLEPOSE_THUNDER }
);

// From video element
const poses = await detector.estimatePoses(videoElement);
for (const pose of poses) {
  for (const kp of pose.keypoints) {
    if (kp.score > 0.3) {
      console.log(`${kp.name}: (${kp.x}, ${kp.y})`);
    }
  }
}

Face detection (BlazeFace)

import '@tensorflow/tfjs-backend-webgl';
import * as blazeface from '@tensorflow-models/blazeface';

const model = await blazeface.load();
const predictions = await model.estimateFaces(videoElement, false);

for (const face of predictions) {
  const [x1, y1] = face.topLeft as [number, number];
  const [x2, y2] = face.bottomRight as [number, number];
  console.log(`Face at (${x1}, ${y1}) to (${x2}, ${y2}), confidence: ${face.probability}`);
}

ONNX Runtime Web

For custom or fine-tuned ONNX models

Run any ONNX model in the browser. WebGPU backend for GPU acceleration, WASM fallback for universal support. Ideal for models you've trained and exported to ONNX format.

npm install onnxruntime-web

import * as ort from 'onnxruntime-web';

// Load model with WebGPU, fallback to WASM
const session = await ort.InferenceSession.create('/models/my-model.onnx', {
  executionProviders: ['webgpu', 'wasm'],
});

// Prepare input (example: image classification, batch=1, channels=3, 224x224)
const inputData = new Float32Array(1 * 3 * 224 * 224);
// ... fill with preprocessed image data ...
const inputTensor = new ort.Tensor('float32', inputData, [1, 3, 224, 224]);

// Run inference
const results = await session.run({ input: inputTensor });
const output = results['output'];
const predictions = Array.from(output.data as Float32Array);

// Find top prediction
const maxIdx = predictions.indexOf(Math.max(...predictions));
console.log(`Predicted class: ${maxIdx}, confidence: ${predictions[maxIdx]}`);

LangChain.js

Chains, RAG, tools, and memory -- in the browser

Build complex AI workflows with prompt chains, retrieval-augmented generation, tool calling, and conversation memory. Works with the FAGS proxy for API key injection.

npm install langchain @langchain/openai @langchain/core

Simple chain

import { ChatOpenAI } from '@langchain/openai';
import { ChatPromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

const session = localStorage.getItem('fags_session');

const model = new ChatOpenAI({
  configuration: {
    baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
    defaultHeaders: { Authorization: `Bearer ${session}` },
  },
  modelName: 'gpt-4o-mini',
});

const prompt = ChatPromptTemplate.fromMessages([
  ['system', 'You are an expert at {topic}. Be concise.'],
  ['human', '{question}'],
]);

const chain = prompt.pipe(model).pipe(new StringOutputParser());
const result = await chain.invoke({
  topic: 'web development',
  question: 'What is the difference between WebGPU and WebGL?',
});

Structured output

import { ChatOpenAI } from '@langchain/openai';
import { z } from 'zod';

const session = localStorage.getItem('fags_session');

const model = new ChatOpenAI({
  configuration: {
    baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
    defaultHeaders: { Authorization: `Bearer ${session}` },
  },
  modelName: 'gpt-4o-mini',
});

const ReviewSchema = z.object({
  score: z.number().min(0).max(100).describe('Code quality score'),
  issues: z.array(z.object({
    severity: z.enum(['error', 'warning', 'info']),
    message: z.string(),
  })),
  summary: z.string(),
});

const structured = model.withStructuredOutput(ReviewSchema);
const review = await structured.invoke('Review this: function add(a,b){return a+b}');
// { score: 75, issues: [...], summary: '...' }

Tool calling

import { ChatOpenAI } from '@langchain/openai';
import { tool } from '@langchain/core/tools';
import { z } from 'zod';

const session = localStorage.getItem('fags_session');

const weatherTool = tool(
  async ({ city }) => {
    // In a real agent, call a weather API here
    return `Weather in ${city}: 22C, sunny`;
  },
  {
    name: 'get_weather',
    description: 'Get current weather for a city',
    schema: z.object({ city: z.string().describe('City name') }),
  }
);

const model = new ChatOpenAI({
  configuration: {
    baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
    defaultHeaders: { Authorization: `Bearer ${session}` },
  },
  modelName: 'gpt-4o-mini',
}).bindTools([weatherTool]);

const result = await model.invoke('What is the weather in Tokyo?');
// Model may return a tool call -- handle it in your agent loop

Vercel AI SDK

Streaming-first, multi-provider AI SDK

Unified API for OpenAI, Anthropic, Google, and more. Streaming out of the box. Works with the FAGS proxy.

npm install ai @ai-sdk/openai

Streaming text

import { createOpenAI } from '@ai-sdk/openai';
import { streamText } from 'ai';

const session = localStorage.getItem('fags_session');

const openai = createOpenAI({
  baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
  apiKey: session ?? '',
});

const result = streamText({
  model: openai('gpt-4o-mini'),
  system: 'You are a helpful assistant.',
  prompt: 'Explain how WebGPU works in 3 sentences.',
});

// Stream chunks to the UI
for await (const chunk of result.textStream) {
  document.getElementById('output')!.textContent += chunk;
}

Generate structured data

import { createOpenAI } from '@ai-sdk/openai';
import { generateObject } from 'ai';
import { z } from 'zod';

const session = localStorage.getItem('fags_session');

const openai = createOpenAI({
  baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
  apiKey: session ?? '',
});

const { object } = await generateObject({
  model: openai('gpt-4o-mini'),
  schema: z.object({
    name: z.string(),
    ingredients: z.array(z.string()),
    steps: z.array(z.string()),
  }),
  prompt: 'Generate a recipe for chocolate chip cookies.',
});
// { name: 'Chocolate Chip Cookies', ingredients: [...], steps: [...] }

Chrome Built-in AI

Zero-cost local AI in Chrome

Chrome 131+ includes a built-in language model (Gemini Nano). No download, no API key, runs entirely on-device. Limited capability but perfect as a free fallback.

No npm install needed -- it's a browser API.

Check availability and generate

async function generateWithBuiltInAI(prompt: string): Promise<string | null> {
  const g = globalThis as any;
  const LM = g.LanguageModel ?? g.ai?.languageModel;

  if (!LM?.create) {
    console.log('Chrome Built-in AI not available');
    return null;
  }

  const session = await LM.create({
    systemPrompt: 'You are a helpful assistant. Be concise.',
  });

  try {
    return await session.prompt(prompt);
  } finally {
    session.destroy?.();
  }
}

// Use it
const answer = await generateWithBuiltInAI('Summarize the benefits of WebGPU.');
if (answer) {
  console.log(answer);
} else {
  // Fall back to another method
}

Streaming response

const g = globalThis as any;
const LM = g.LanguageModel ?? g.ai?.languageModel;

if (LM?.create) {
  const session = await LM.create({ systemPrompt: 'Be helpful and concise.' });

  const stream = session.promptStreaming('List 5 uses for WebAssembly.');
  for await (const text of stream) {
    // `text` is the cumulative response so far
    document.getElementById('output')!.textContent = text;
  }

  session.destroy?.();
}

Limitations: Small model (Gemini Nano), no vision, no tool calling, no structured output, Chrome-only. Best used as a free fallback when the user has no API key configured.

Ollama

Local LLM server

Users install Ollama on their machine and run models locally. Your agent calls localhost:11434. Completely free, fully private, but requires user setup.

User installs from ollama.com, then runs ollama run llama3.2

Chat completion with streaming

async function chatWithOllama(
  messages: Array<{ role: string; content: string }>,
  onChunk?: (text: string) => void,
): Promise<string> {
  const response = await fetch('http://localhost:11434/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: 'llama3.2',
      messages,
      stream: true,
    }),
  });

  if (!response.ok) throw new Error('Ollama not running or model not installed');

  const reader = response.body?.getReader();
  if (!reader) throw new Error('No response body');

  const decoder = new TextDecoder();
  let fullText = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value, { stream: true });

    for (const line of chunk.split('\n')) {
      if (!line.trim()) continue;
      try {
        const json = JSON.parse(line);
        const token = json.message?.content ?? '';
        if (token) {
          fullText += token;
          onChunk?.(fullText);
        }
      } catch {}
    }
  }

  return fullText;
}

// Check if Ollama is available
async function isOllamaAvailable(): Promise<boolean> {
  try {
    const res = await fetch('http://localhost:11434/api/tags');
    return res.ok;
  } catch {
    return false;
  }
}

// List installed models
async function listModels(): Promise<string[]> {
  const res = await fetch('http://localhost:11434/api/tags');
  if (!res.ok) return [];
  const data = await res.json();
  return data.models?.map((m: any) => m.name) ?? [];
}

Workers AI (PAGS only)

Server-side inference on Cloudflare

Workers AI runs models on Cloudflare's GPU fleet. Not available for FAGS (browser-only agents). If your agent needs server-side AI, build it on ProAgentStore (PAGS) instead.

Access via Cloudflare Worker binding -- no npm install needed.

// This runs in a Cloudflare Worker (PAGS), NOT in the browser
export default {
  async fetch(request: Request, env: Env) {
    const result = await env.AI.run('@cf/meta/llama-3.1-8b-instruct', {
      messages: [
        { role: 'system', content: 'You are a helpful assistant.' },
        { role: 'user', content: 'Explain quantum computing briefly.' },
      ],
    });

    return Response.json(result);
  },
};

Choosing the right framework

  • Pure classification/scoring? Write a heuristic -- no framework needed.
  • Image/audio/text ML? Use Transformers.js. It has the largest model library and best browser support.
  • Pose/face/hand tracking? Use TensorFlow.js task libraries (MoveNet, BlazeFace, MediaPipe).
  • Custom trained model? Export to ONNX and use ONNX Runtime Web.
  • Need LLM reasoning? Use direct proxy calls for simplicity, or LangChain.js for chains/RAG/tools.
  • Streaming UI? Vercel AI SDK has the cleanest streaming API.
  • Free fallback? Chrome Built-in AI for simple tasks, Ollama for full models.
  • Server-side AI? Build on PAGS with Workers AI.
