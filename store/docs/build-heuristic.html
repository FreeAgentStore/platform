Build a Heuristic Library

A heuristic library is a pure TypeScript function that classifies, scores, or parses text using weighted keyword dictionaries, structural patterns, and rule-based logic. No model download, no API key, sub-millisecond results.

How heuristic agents evolve: You start with hand-written rules. Collect failure cases from users. Feed the examples to an LLM with "write better code." Eval the new code against all examples. Ship if accuracy improves. Repeat. Each version gets better without ever downloading a model.

What makes a good heuristic

  • The task has clear categories (spam/not-spam, positive/negative, urgent/normal)
  • Keyword signals are strong enough to get 85%+ accuracy
  • Speed matters more than perfection (filtering, triage, pre-processing)
  • Zero dependencies -- pure TypeScript, no model, no API key

Examples on the store: sentiment, clickbait-detector, urgency-detector, sarcasm-detector, email-classifier.

Full example: Spam Detector

This heuristic scores text on multiple dimensions -- keyword presence, structural signals, and contextual patterns -- then normalizes to a 0-1 spam probability.

web/src/heuristic.ts

/**
 * Spam Detector heuristic -- LLM-evolved, deterministic, no model needed.
 * v1: keyword scoring + structural analysis + negation handling
 */

// ── Types ────────────────────────────────────────────────────────────────────

export interface SpamResult {
  isSpam: boolean;
  score: number;       // 0 (ham) to 1 (spam)
  confidence: number;  // 0 (no signal) to 1 (strong signal)
  reasons: string[];
}

// ── Keyword dictionaries ─────────────────────────────────────────────────────

const SPAM_WORDS: Record<string, number> = {
  // Financial bait
  'free': 2, 'winner': 3, 'prize': 3, 'lottery': 3, 'jackpot': 3,
  'cash': 2, 'money': 2, 'earn': 2, 'income': 2, 'profit': 2,
  'millionaire': 3, 'billion': 2, 'investment': 1, 'crypto': 2,
  // Urgency / pressure
  'urgent': 3, 'immediately': 2, 'expires': 2, 'limited': 2,
  'act now': 3, 'hurry': 2, 'deadline': 1, 'last chance': 3,
  // Action demands
  'click here': 3, 'subscribe': 1, 'unsubscribe': 1, 'buy now': 3,
  'order now': 3, 'sign up': 1, 'apply now': 2, 'claim': 2,
  // Shady offers
  'viagra': 3, 'pharmacy': 2, 'pills': 2, 'weight loss': 2,
  'miracle': 3, 'guaranteed': 2, 'no obligation': 2, 'risk free': 2,
  'no cost': 2, 'double your': 3, 'congratulations': 3,
  // Phishing
  'verify your account': 3, 'confirm your identity': 3,
  'suspended': 2, 'unauthorized': 2, 'security alert': 2,
  'password': 1, 'ssn': 3, 'social security': 3,
};

const LEGIT_WORDS: Record<string, number> = {
  // Professional
  'meeting': 2, 'schedule': 2, 'agenda': 2, 'project': 2,
  'deadline': 1, 'review': 1, 'update': 1, 'team': 2,
  'report': 2, 'quarterly': 2, 'budget': 1, 'proposal': 2,
  // Personal
  'thanks': 1, 'appreciate': 1, 'regards': 1, 'sincerely': 1,
  'attached': 1, 'following up': 1, 'discussed': 1, 'agreed': 1,
  // Technical
  'repository': 2, 'pull request': 2, 'commit': 2, 'deploy': 2,
  'merge': 2, 'branch': 1, 'documentation': 1, 'release': 1,
};

const NEGATORS = new Set([
  'not', "n't", 'no', 'never', 'neither', 'nor',
  'hardly', 'barely', 'without',
]);

// ── Structural scoring ───────────────────────────────────────────────────────

function scoreStructure(text: string): { score: number; reasons: string[] } {
  let score = 0;
  const reasons: string[] = [];

  // ALL CAPS ratio
  const words = text.split(/\s+/).filter(Boolean);
  const capsWords = words.filter(w => w.length > 2 && w === w.toUpperCase() && /[A-Z]/.test(w));
  const capsRatio = words.length > 0 ? capsWords.length / words.length : 0;
  if (capsRatio > 0.3) {
    score += 3;
    reasons.push('excessive ALL CAPS');
  }

  // Excessive punctuation
  const exclamations = (text.match(/!/g) || []).length;
  const questions = (text.match(/\?/g) || []).length;
  if (exclamations > 3) {
    score += 2;
    reasons.push('excessive exclamation marks');
  }
  if (questions > 3 && exclamations > 1) {
    score += 1;
    reasons.push('mixed excessive punctuation');
  }

  // Dollar signs / currency patterns
  const moneyPatterns = (text.match(/\$[\d,]+/g) || []).length;
  if (moneyPatterns > 1) {
    score += 2;
    reasons.push('multiple money amounts');
  }

  // URLs count
  const urlCount = (text.match(/https?:\/\/\S+/gi) || []).length;
  if (urlCount > 3) {
    score += 2;
    reasons.push('excessive URLs');
  }

  // Email address harvesting patterns
  if (/reply to .+@/i.test(text) || /send .+@/i.test(text)) {
    score += 2;
    reasons.push('suspicious email reference');
  }

  return { score, reasons };
}

// ── Main classifier ──────────────────────────────────────────────────────────

export function detectSpam(text: string): SpamResult {
  if (!text.trim()) {
    return { isSpam: false, score: 0, confidence: 0, reasons: [] };
  }

  const lower = text.toLowerCase();
  const words = lower.replace(/[^a-z'\s-]/g, ' ').split(/\s+/).filter(Boolean);
  const reasons: string[] = [];

  let spamScore = 0;
  let legitScore = 0;
  let totalWeight = 0;

  // ── Multi-word phrase matching ──
  for (const [phrase, weight] of Object.entries(SPAM_WORDS)) {
    if (phrase.includes(' ') && lower.includes(phrase)) {
      spamScore += weight;
      totalWeight += weight;
      reasons.push(`spam phrase: "${phrase}"`);
    }
  }
  for (const [phrase, weight] of Object.entries(LEGIT_WORDS)) {
    if (phrase.includes(' ') && lower.includes(phrase)) {
      legitScore += weight;
      totalWeight += weight;
    }
  }

  // ── Single-word scoring with negation ──
  for (let i = 0; i < words.length; i++) {
    const word = words[i];
    const sw = SPAM_WORDS[word] ?? 0;
    const lw = LEGIT_WORDS[word] ?? 0;
    if (sw === 0 && lw === 0) continue;

    // Check for negation in previous 3 words
    let negated = false;
    for (let j = Math.max(0, i - 3); j < i; j++) {
      if (NEGATORS.has(words[j]) || words[j].endsWith("n't")) {
        negated = true;
        break;
      }
    }

    if (negated) {
      // Negation weakens the signal rather than fully flipping it
      legitScore += sw * 0.3;
      spamScore += lw * 0.3;
      totalWeight += Math.max(sw, lw) * 0.3;
    } else {
      spamScore += sw;
      legitScore += lw;
      totalWeight += Math.max(sw, lw);
      if (sw >= 3) reasons.push(`spam keyword: "${word}"`);
    }
  }

  // ── Structural analysis ──
  const structural = scoreStructure(text);
  spamScore += structural.score;
  totalWeight += structural.score;
  reasons.push(...structural.reasons);

  // ── Normalize to 0-1 ──
  const raw = totalWeight > 0 ? (spamScore - legitScore) / totalWeight : 0;
  const score = Math.max(0, Math.min(1, (raw + 1) / 2));
  const confidence = Math.min(totalWeight / 8, 1);
  const isSpam = score > 0.55 && confidence > 0.2;

  return {
    isSpam,
    score: Math.round(score * 100) / 100,
    confidence: Math.round(confidence * 100) / 100,
    reasons: isSpam ? reasons.slice(0, 5) : [],
  };
}

Key design patterns

  • Weighted dictionaries -- high-weight words (3) are strong signals, low-weight words (1) only contribute in aggregate
  • Negation window -- checks the previous 3 words for negators ("not free" should not trigger spam)
  • Multi-word phrases -- "click here" and "act now" are matched as phrases, not individual words
  • Structural scoring -- ALL CAPS ratio, punctuation abuse, money patterns, URL density
  • Score normalization -- raw score is normalized to 0-1 range with a confidence measure
  • Threshold + confidence gate -- both score and confidence must pass thresholds to flag as spam

3 Write tests

Create web/src/heuristic.test.ts:

import { describe, it, expect } from 'vitest';
import { detectSpam } from './heuristic';

describe('spam detector', () => {
  it('detects obvious spam', () => {
    const r = detectSpam('CONGRATULATIONS! You have WON $1,000,000!!! Click here to claim your prize NOW!');
    expect(r.isSpam).toBe(true);
    expect(r.score).toBeGreaterThan(0.7);
    expect(r.reasons.length).toBeGreaterThan(0);
  });

  it('passes legitimate email', () => {
    const r = detectSpam('Hi team, attached is the quarterly report. Please review before our meeting on Thursday.');
    expect(r.isSpam).toBe(false);
    expect(r.score).toBeLessThan(0.5);
  });

  it('handles negation', () => {
    const r = detectSpam('This is not free and there is no prize');
    expect(r.isSpam).toBe(false);
  });

  it('catches structural spam signals', () => {
    const r = detectSpam('BUY NOW!!! BEST DEAL EVER!!! CLICK HERE!!! $$$');
    expect(r.isSpam).toBe(true);
    expect(r.reasons).toContain('excessive ALL CAPS');
  });

  it('detects phishing language', () => {
    const r = detectSpam('Your account has been suspended. Verify your account immediately to avoid losing access.');
    expect(r.isSpam).toBe(true);
  });

  it('passes technical discussion', () => {
    const r = detectSpam('Opened a pull request for the new deploy pipeline. Merged the branch after review.');
    expect(r.isSpam).toBe(false);
  });

  it('handles empty input', () => {
    const r = detectSpam('');
    expect(r.isSpam).toBe(false);
    expect(r.score).toBe(0);
  });

  it('returns confidence based on signal density', () => {
    const strong = detectSpam('Free cash prize winner lottery jackpot congratulations');
    const weak = detectSpam('The free tier includes basic features');
    expect(strong.confidence).toBeGreaterThan(weak.confidence);
  });
});

Evolving accuracy

Heuristic agents improve through an LLM-driven evolution loop:

  1. Collect failures -- users report "this was flagged as spam but it's not" or "this spam got through"
  2. Accumulate examples -- store input/expected pairs in a test file
  3. Feed to LLM -- "Here is the current code and these failing examples. Write improved code that passes all examples while keeping existing accuracy."
  4. Evaluate -- run the full test suite. If accuracy improves, ship it.
  5. Repeat -- each version gets better. Track accuracy in agent.json.

The code is the model. There is no training step, no weights file, no model download. The LLM writes better TypeScript each iteration.

Accuracy tracking

Every heuristic agent tracks its evolution in agent.json:

"evolution": {
  "versions": 3,      // how many evolution cycles
  "examples": 500,    // total labeled examples used
  "accuracy": 92      // % correct on held-out test set
}

This is displayed on the agent's store page so users can see how mature the heuristic is. Higher versions + more examples = more trustworthy.

Exporting as a library

Your heuristic is automatically available as an importable library:

// npm
npm install @freeagentstore/spam-detector
import { detectSpam } from '@freeagentstore/spam-detector';

// ESM URL (zero install)
import { detectSpam } from 'https://freeagentstore.online/pkg/spam-detector/index.js';

Keep your core logic in heuristic.ts with no DOM or React dependencies so it works in any JavaScript runtime -- browser, Node, Deno, Bun, Workers.
