Build an AI Agent

An AI agent uses a large language model (OpenAI, Claude, Gemini, Groq, etc.) via the user's own API key. The platform stores keys encrypted (AES-256-GCM) and injects them server-side through a proxy -- your agent never sees the key.

How the proxy works

The inference cascade: Your agent calls the FAGS proxy. If the user has an API key configured, the proxy decrypts it and forwards the request to the provider. If no key is configured, the agent can fall back to Chrome Built-in AI (free, local) or Ollama (local LLM). The user pays their provider directly -- the platform charges nothing.
  1. User signs in with GitHub and adds their API key at /v1/keys
  2. Key is encrypted with AES-256-GCM (envelope encryption) and stored in D1
  3. Your agent sends requests to /v1/proxy/{provider-host}/{path}
  4. The proxy decrypts the key, injects it into the request headers, forwards to the provider
  5. Response streams back through the proxy to the browser

Supported providers

Full example: Code Reviewer

This agent takes code as input, sends it to OpenAI via the proxy for review, streams the response, and displays issues, suggestions, and a quality score.

web/src/inference.ts

const PROXY_BASE = 'https://freeagentstore.online/v1/proxy';

function getSession(): string | null {
  return localStorage.getItem('fags_session');
}

// ── Check if user has a key for a provider ───────────────────────────────────

export async function checkKeyStatus(): Promise<Record<string, boolean>> {
  const session = getSession();
  if (!session) return {};

  const res = await fetch('https://freeagentstore.online/v1/keys/status', {
    headers: { Authorization: `Bearer ${session}` },
  });
  if (!res.ok) return {};

  const data = await res.json();
  return data.providers ?? {};
}

// ── Redirect to key management if no key ─────────────────────────────────────

export function redirectToKeySetup(provider: string): void {
  const returnUrl = encodeURIComponent(window.location.href);
  window.location.href = `/v1/keys?provider=${provider}&return=${returnUrl}`;
}

// ── Main inference: proxy with streaming ─────────────────────────────────────

export interface ReviewResult {
  issues: Array<{ severity: 'error' | 'warning' | 'info'; line?: number; message: string }>;
  suggestions: string[];
  score: number;
  summary: string;
}

export async function reviewCode(
  code: string,
  language: string,
  onChunk?: (text: string) => void,
): Promise<string> {
  // Try proxy first, then fallbacks
  try {
    return await reviewViaProxy(code, language, onChunk);
  } catch (err: any) {
    if (err.message === 'no-key') {
      // User has no key -- try free fallbacks
    } else if (err.message === 'no-session') {
      // Not logged in -- try free fallbacks
    } else {
      throw err;
    }
  }

  // Fallback 1: Chrome Built-in AI
  try {
    return await reviewViaBuiltInAI(code, language, onChunk);
  } catch {
    // Not available
  }

  // Fallback 2: Ollama (local)
  try {
    return await reviewViaOllama(code, language, onChunk);
  } catch {
    // Not available
  }

  throw new Error(
    'No AI backend available. Add your API key at /v1/keys, ' +
    'enable Chrome Built-in AI, or run Ollama locally.'
  );
}

// ── Proxy-based review (OpenAI) ──────────────────────────────────────────────

async function reviewViaProxy(
  code: string,
  language: string,
  onChunk?: (text: string) => void,
): Promise<string> {
  const session = getSession();
  if (!session) throw new Error('no-session');

  const response = await fetch(
    `${PROXY_BASE}/api.openai.com/v1/chat/completions`,
    {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${session}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        model: 'gpt-4o-mini',
        temperature: 0.3,
        stream: true,
        messages: [
          {
            role: 'system',
            content: `You are a senior code reviewer. Review the provided ${language} code.
Respond with a JSON object:
{
  "issues": [{ "severity": "error"|"warning"|"info", "line": number|null, "message": "..." }],
  "suggestions": ["..."],
  "score": 0-100,
  "summary": "one paragraph summary"
}
Be specific about line numbers when possible. Focus on bugs, security issues, performance, and readability.`,
          },
          {
            role: 'user',
            content: `Review this ${language} code:\n\n\`\`\`${language}\n${code}\n\`\`\``,
          },
        ],
      }),
    },
  );

  if (!response.ok) {
    const text = await response.text().catch(() => '');
    if (response.status === 401 || response.status === 403) {
      throw new Error('no-key');
    }
    throw new Error(`Proxy error ${response.status}: ${text}`);
  }

  // Stream the response
  const reader = response.body?.getReader();
  if (!reader) throw new Error('No response body');

  const decoder = new TextDecoder();
  let fullText = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value, { stream: true });

    for (const line of chunk.split('\n')) {
      if (!line.startsWith('data: ')) continue;
      const data = line.slice(6).trim();
      if (data === '[DONE]') continue;
      try {
        const json = JSON.parse(data);
        const token = json.choices?.[0]?.delta?.content ?? '';
        if (token) {
          fullText += token;
          onChunk?.(fullText);
        }
      } catch {}
    }
  }

  return fullText;
}

// ── Chrome Built-in AI fallback ──────────────────────────────────────────────

async function reviewViaBuiltInAI(
  code: string,
  language: string,
  onChunk?: (text: string) => void,
): Promise<string> {
  const g = globalThis as any;
  const LM = g.LanguageModel ?? g.ai?.languageModel;
  if (!LM?.create) throw new Error('not-available');

  const session = await LM.create({
    systemPrompt: `You are a code reviewer. Review ${language} code for bugs, issues, and improvements. Keep it concise.`,
  });

  const result = await session.prompt(
    `Review this code:\n\n\`\`\`${language}\n${code}\n\`\`\``
  );
  session.destroy?.();
  onChunk?.(result);
  return result;
}

// ── Ollama fallback ──────────────────────────────────────────────────────────

async function reviewViaOllama(
  code: string,
  language: string,
  onChunk?: (text: string) => void,
): Promise<string> {
  const response = await fetch('http://localhost:11434/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: 'llama3.2',
      stream: true,
      messages: [
        { role: 'system', content: `You are a code reviewer. Review ${language} code for bugs and improvements.` },
        { role: 'user', content: `Review this:\n\n\`\`\`${language}\n${code}\n\`\`\`` },
      ],
    }),
  });

  if (!response.ok) throw new Error('Ollama unavailable');

  const reader = response.body?.getReader();
  if (!reader) throw new Error('No response body');

  const decoder = new TextDecoder();
  let fullText = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const chunk = decoder.decode(value, { stream: true });
    for (const line of chunk.split('\n')) {
      if (!line.trim()) continue;
      try {
        const json = JSON.parse(line);
        const token = json.message?.content ?? '';
        if (token) {
          fullText += token;
          onChunk?.(fullText);
        }
      } catch {}
    }
  }

  return fullText;
}

// ── Parse structured review from LLM response ───────────────────────────────

export function parseReview(raw: string): ReviewResult {
  // Try to extract JSON from the response
  const jsonMatch = raw.match(/\{[\s\S]*\}/);
  if (jsonMatch) {
    try {
      const parsed = JSON.parse(jsonMatch[0]);
      return {
        issues: Array.isArray(parsed.issues) ? parsed.issues : [],
        suggestions: Array.isArray(parsed.suggestions) ? parsed.suggestions : [],
        score: typeof parsed.score === 'number' ? parsed.score : 50,
        summary: typeof parsed.summary === 'string' ? parsed.summary : raw,
      };
    } catch {}
  }

  // Fallback: return raw text as summary
  return { issues: [], suggestions: [], score: 50, summary: raw };
}

web/src/App.tsx

import { useState, useEffect } from 'react';
import { reviewCode, parseReview, checkKeyStatus, redirectToKeySetup, type ReviewResult } from './inference';

export default function App() {
  const [code, setCode] = useState('');
  const [language, setLanguage] = useState('typescript');
  const [reviewing, setReviewing] = useState(false);
  const [stream, setStream] = useState('');
  const [result, setResult] = useState<ReviewResult | null>(null);
  const [hasKey, setHasKey] = useState<boolean | null>(null);
  const [error, setError] = useState<string | null>(null);

  // Check key status on mount
  useEffect(() => {
    checkKeyStatus().then(providers => {
      setHasKey(Object.values(providers).some(Boolean));
    });
  }, []);

  const handleReview = async () => {
    if (!code.trim()) return;
    setReviewing(true);
    setStream('');
    setResult(null);
    setError(null);

    try {
      const raw = await reviewCode(code, language, (text) => setStream(text));
      setResult(parseReview(raw));
    } catch (err: any) {
      setError(err.message);
    } finally {
      setReviewing(false);
    }
  };

  return (
    <div style={{ maxWidth: 640, margin: '2rem auto', padding: '0 1rem' }}>
      <h1>Code Reviewer</h1>
      <p>Paste your code for an AI-powered review. Uses your API key via the platform proxy.</p>

      {hasKey === false && (
        <div style={{ background: 'rgba(245,158,11,0.1)', border: '1px solid rgba(245,158,11,0.3)', borderRadius: 12, padding: '1rem', marginBottom: '1rem' }}>
          <p style={{ margin: 0, fontSize: '0.9rem' }}>
            No API key configured.{' '}
            <a href="#" onClick={(e) => { e.preventDefault(); redirectToKeySetup('openai'); }}>
              Add your OpenAI key
            </a>
            {' '}for the best experience, or use Chrome Built-in AI / Ollama as a free fallback.
          </p>
        </div>
      )}

      <select value={language} onChange={e => setLanguage(e.target.value)}
        style={{ background: '#171717', color: '#fafafa', border: '1px solid #262626', borderRadius: 8, padding: '0.5rem', marginBottom: '0.5rem', width: '100%' }}>
        <option value="typescript">TypeScript</option>
        <option value="javascript">JavaScript</option>
        <option value="python">Python</option>
        <option value="rust">Rust</option>
        <option value="go">Go</option>
      </select>

      <textarea
        value={code}
        onChange={e => setCode(e.target.value)}
        placeholder="Paste your code here..."
        rows={12}
        style={{ width: '100%', background: '#171717', color: '#fafafa', border: '1px solid #262626', borderRadius: 12, padding: '1rem', fontFamily: 'monospace', fontSize: '0.85rem', resize: 'vertical' }}
      />

      <button onClick={handleReview} disabled={reviewing || !code.trim()}
        style={{ marginTop: '0.5rem', padding: '0.6rem 1.5rem', background: '#7c3aed', color: 'white', border: 'none', borderRadius: 10, fontWeight: 600, cursor: 'pointer', opacity: reviewing ? 0.6 : 1 }}>
        {reviewing ? 'Reviewing...' : 'Review Code'}
      </button>

      {stream && !result && (
        <pre style={{ marginTop: '1rem', whiteSpace: 'pre-wrap', wordBreak: 'break-word' }}>{stream}</pre>
      )}

      {error && <p style={{ color: '#ef4444', marginTop: '1rem' }}>{error}</p>}

      {result && (
        <div style={{ marginTop: '1rem' }}>
          <div style={{ display: 'flex', alignItems: 'center', gap: '1rem', marginBottom: '1rem' }}>
            <div style={{ fontSize: '2rem', fontWeight: 700, color: result.score >= 80 ? '#4ade80' : result.score >= 50 ? '#fbbf24' : '#ef4444' }}>
              {result.score}/100
            </div>
            <p style={{ margin: 0 }}>{result.summary}</p>
          </div>

          {result.issues.length > 0 && (
            <div>
              <h3>Issues</h3>
              {result.issues.map((issue, i) => (
                <div key={i} style={{ background: '#171717', border: '1px solid #262626', borderRadius: 8, padding: '0.75rem', marginBottom: '0.5rem' }}>
                  <span style={{ color: issue.severity === 'error' ? '#ef4444' : issue.severity === 'warning' ? '#fbbf24' : '#60a5fa', fontWeight: 600, fontSize: '0.82rem' }}>
                    {issue.severity.toUpperCase()}
                  </span>
                  {issue.line && <span style={{ color: '#737373', fontSize: '0.82rem' }}> line {issue.line}</span>}
                  <p style={{ margin: '0.25rem 0 0', fontSize: '0.88rem' }}>{issue.message}</p>
                </div>
              ))}
            </div>
          )}

          {result.suggestions.length > 0 && (
            <div>
              <h3>Suggestions</h3>
              <ul>{result.suggestions.map((s, i) => <li key={i}>{s}</li>)}</ul>
            </div>
          )}
        </div>
      )}
    </div>
  );
}

Key vault SDK patterns

The standard flow for agents that need an API key:

// 1. Check if user has a key
const status = await checkKeyStatus();
const hasOpenAI = status['openai'] === true;

// 2. If no key, prompt the user
if (!hasOpenAI) {
  // Option A: Redirect to key management page
  redirectToKeySetup('openai');

  // Option B: Show inline prompt with link
  const manageUrl = '/v1/keys?provider=openai&return=' + encodeURIComponent(location.href);
}

// 3. Call proxy (key is injected server-side)
const response = await fetch('/v1/proxy/api.openai.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${session}`,  // FAGS session token, NOT the API key
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ model: 'gpt-4o-mini', messages: [...] }),
});

// 4. Handle "no key" error gracefully
if (response.status === 403) {
  const data = await response.json();
  if (data.error === 'no_key') {
    // Redirect to: data.manage_url
  }
}
Never ask users for their API key directly. The platform handles key storage and injection. Your agent sends requests to the proxy with the FAGS session token. The proxy decrypts the user's key and injects it. The key never touches browser JavaScript.

Inference cascade

The recommended pattern is to try the proxy first, then fall back to free alternatives:

  1. Proxy (best quality) -- user's own API key, full model selection
  2. Chrome Built-in AI (free, local) -- available in Chrome 131+, limited capability
  3. Ollama (free, local) -- user must install and run Ollama separately

This pattern is implemented in the Code Reviewer example above. The reviewCode() function tries each backend in order and returns the first successful result.

Using LangChain.js

LangChain.js works in the browser. Point it at the FAGS proxy as the base URL:

import { ChatOpenAI } from '@langchain/openai';
import { HumanMessage, SystemMessage } from '@langchain/core/messages';
import { StringOutputParser } from '@langchain/core/output_parsers';

const session = localStorage.getItem('fags_session');

const model = new ChatOpenAI({
  configuration: {
    baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
    defaultHeaders: {
      Authorization: `Bearer ${session}`,
    },
  },
  modelName: 'gpt-4o-mini',
  temperature: 0.3,
});

// Simple chain
const parser = new StringOutputParser();
const chain = model.pipe(parser);

const result = await chain.invoke([
  new SystemMessage('You are a helpful assistant.'),
  new HumanMessage('Explain WebGPU in one paragraph.'),
]);
console.log(result);

LangChain.js with RAG

Combine the smart-search agent (MiniLM embeddings) with LangChain for retrieval-augmented generation:

import { ChatOpenAI } from '@langchain/openai';
import { PromptTemplate } from '@langchain/core/prompts';
import { StringOutputParser } from '@langchain/core/output_parsers';

// Use the smart-search agent for embeddings + retrieval
import { createIndex, search } from '@freeagentstore/smart-search';

// Build an index from your documents
const index = await createIndex([
  'WebGPU is a modern graphics API for the web.',
  'WASM provides near-native performance in browsers.',
  'Transformers.js runs HuggingFace models in the browser.',
  // ... more documents
]);

// Retrieve relevant context
const query = 'How do I run ML models in the browser?';
const relevant = await search(index, query, { topK: 3 });
const context = relevant.map(r => r.text).join('\n\n');

// Generate answer with context
const session = localStorage.getItem('fags_session');
const model = new ChatOpenAI({
  configuration: {
    baseURL: 'https://freeagentstore.online/v1/proxy/api.openai.com/v1',
    defaultHeaders: { Authorization: `Bearer ${session}` },
  },
  modelName: 'gpt-4o-mini',
});

const prompt = PromptTemplate.fromTemplate(
  `Answer based on this context:\n\n{context}\n\nQuestion: {question}`
);

const chain = prompt.pipe(model).pipe(new StringOutputParser());
const answer = await chain.invoke({ context, question: query });

Using Chrome Built-in AI

Chrome 131+ includes a built-in language model. Zero cost, zero download, fully local:

// Check availability
const g = globalThis as any;
const LM = g.LanguageModel ?? g.ai?.languageModel;

if (LM?.create) {
  // Create a session with a system prompt
  const session = await LM.create({
    systemPrompt: 'You are a helpful assistant.',
  });

  // Simple prompt
  const result = await session.prompt('What is WebGPU?');
  console.log(result);

  // Streaming
  const stream = session.promptStreaming('Explain WASM.');
  for await (const chunk of stream) {
    console.log(chunk);  // cumulative text
  }

  // Clean up
  session.destroy();
} else {
  console.log('Chrome Built-in AI not available');
}

Limitations: smaller model, no vision, no tool calling, Chrome-only. Good as a free fallback for simple tasks.

Conversation memory

For chat-style agents, store conversation history in IndexedDB:

// Simple conversation store using IndexedDB
const DB_NAME = 'code-reviewer-chats';
const STORE = 'messages';

async function openDB(): Promise<IDBDatabase> {
  return new Promise((resolve, reject) => {
    const req = indexedDB.open(DB_NAME, 1);
    req.onupgradeneeded = () => {
      req.result.createObjectStore(STORE, { keyPath: 'id', autoIncrement: true });
    };
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error);
  });
}

export async function saveMessage(role: string, content: string): Promise<void> {
  const db = await openDB();
  const tx = db.transaction(STORE, 'readwrite');
  tx.objectStore(STORE).add({ role, content, timestamp: Date.now() });
}

export async function getHistory(): Promise<Array<{ role: string; content: string }>> {
  const db = await openDB();
  const tx = db.transaction(STORE, 'readonly');
  return new Promise((resolve, reject) => {
    const req = tx.objectStore(STORE).getAll();
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error);
  });
}
