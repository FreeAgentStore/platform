Contribute

FreeAgentStore is open source and community-driven. Build an AI tool, publish it, and share it with the world.

What to build

Heuristic classifiers

The sweet spot. Write a keyword-scoring classifier for a specific use case. The code is evolved by an LLM from data — ship pure JS, zero model, instant results. Examples: sentiment, intent, urgency, formality, clickbait, sarcasm detection.

Good candidates: spam detection, fake review detection, resume quality scoring, headline quality, code smell detection, commit message quality, SEO scoring.

Parsers / extractors

Take messy real-world input, return structured data. Examples: date parser, address parser, name parser, email classifier, code detector.

Good candidates: phone number parser, credit card validator, URL classifier, cron expression parser, user agent parser.

Model-based agents

Combine a Transformers.js model with domain-specific heuristics. The model does the heavy lifting, the heuristic adds real value. Examples: food analyzer, plant identifier, receipt scanner.

Good candidates: outfit rater, meme reader, accent detector, music mood classifier.

Game AI

Pure math libraries for game developers. Zero deps, 60fps capable, importable by FreeGameStore games. Examples: steering behaviors, behavior trees, physics simulation.

Good candidates: pathfinding (A*), procedural terrain, wave function collapse, dialogue systems.

How to contribute

1. Build your agent

npx @freeagentstore/cli init my-agent --template heuristic
cd my-agent
npm install
npm run dev

Templates: heuristic (pure TS), built-in-ai (Chrome AI), model (ONNX)

2. Follow the rules

  • MIT license — required for all free agents
  • Pure TypeScript core — no React/DOM deps in the logic file
  • Under 1MB bundle (excluding models)
  • No cloud AI calls — models run in browser, not on a server
  • No tracking — no analytics, no telemetry
  • Dark theme — neutral-950/900/800, Manrope + Fraunces fonts

3. Test it

npx @freeagentstore/cli check

All 9 compliance checks must pass.

4. Publish

npx @freeagentstore/cli publish

Creates a GitHub repo in the FreeAgentStore org, deploys to R2, registers the route. Your agent is live.

Improving existing agents

Every agent is its own repo at github.com/FreeAgentStore. Fork any agent, improve it, submit a PR.

For evolved heuristic agents: if you find a case where the classifier is wrong, open an issue with the input and expected output. These examples accumulate and drive the next evolution cycle.

Quality standards

  • Agents should solve a real problem, not just wrap a model
  • Heuristic agents must track accuracy: "evolution": { "versions": 1, "examples": 500, "accuracy": 90 }
  • Model agents must add domain value on top of raw model output
  • Write tests for your core logic
  • Write a clear README with API docs and usage examples
