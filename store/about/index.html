About FreeAgentStore

FreeAgentStore is a curated collection of AI-powered tools that run entirely in your browser. No cloud servers, no API keys required for free agents, no subscription. Your data never leaves your device.

Three types of AI tools

Libraries

Pure TypeScript functions — sentiment analysis, date parsing, language detection, profanity filtering, and more. Import via npm or ESM URL. Zero download, instant results.

Models

AI models that download once and run on your GPU via WebGPU/WASM. Food recognition, plant identification, semantic search, document scanning. Powered by Transformers.js.

Agents

Full AI assistants that use your own API key (OpenAI, Claude, Gemini). The platform securely stores your key and injects it server-side. You pay your provider directly.

How it works

Every tool on FreeAgentStore runs in your browser. For libraries and models, there's zero server cost — the code executes on your device. For agents that need an LLM, you bring your own API key. The platform encrypts it (AES-256-GCM) and injects it via a proxy so your key never touches the browser.

Open source

Every agent is open source (MIT license) with its own GitHub repo in the FreeAgentStore organization. Fork any agent, improve it, submit a PR. The heuristic agents evolve from user feedback — each version is better than the last.
